# Definition of Done

Задача считается завершённой, только если выполнены все пункты.

## Поведение

- [ ] Ожидаемое поведение сформулировано до изменений.
- [ ] Изменение действительно решает задачу, а не скрывает симптом.
- [ ] Существующее поведение не сломано без явного требования.

## Код

- [ ] Diff минимален и не затрагивает несвязанные файлы.
- [ ] Использован существующий паттерн модуля/страницы.
- [ ] Нет мёртвого кода, отладочных логов и временных обходов.
- [ ] Нет секретов, токенов и персональных данных в коде/логах.

## Контракты

- [ ] Параметры доходят от UI до сервиса/адаптера.
- [ ] Ответ API содержит поля, которые рендерит UI.
- [ ] Сохранение в БД проверено, если менялась схема/данные.
- [ ] RBAC/permissions соответствуют операции.
- [ ] Money/PII-границы проверены для финансовых и клиентских изменений.

## Build и тесты

- [ ] `backend`: `npm run build`
- [ ] `frontend`: `npm run build`
- [ ] Точечные тесты на новое поведение/расчёт
- [ ] Миграция проверена, если менялась Prisma-схема

## Проверка

- [ ] API-проверка для серверной логики
- [ ] Браузерная проверка для UI/UX
- [ ] RU/AZ/EN для новых пользовательских строк
- [ ] Мобильная ширина для layout-изменений
- [ ] Живые состояния доходят до терминального статуса

## Отчёт

- [ ] Указано, что изменено и где.
- [ ] Указано, чем именно проверено.
- [ ] Указано, что не проверено/осталось ограничением.
- [ ] Есть коммит и push.

## Не считается выполнением

```text
«сборка прошла» без проверки поведения
«поле появилось» без проверки данных
«цена считается» без проверки состава/валюты/периода
«статус обновится» без проверки polling/терминального состояния
```
