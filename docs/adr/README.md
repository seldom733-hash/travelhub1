# Architecture Decision Records

ADR фиксируют решения, которые дорого менять задним числом: границы доменов,
источники истины, форматы расчётов, интеграции и правила безопасности.

## Формат

```text
docs/adr/NNNN-short-title.md
```

Структура:

```markdown
# NNNN — Название

- Статус: proposed | accepted | superseded
- Дата:
- Контекст:
- Решение:
- Последствия:
- Альтернативы:
```

## Правила

- Один ADR — одно решение.
- Решение фиксируется до или сразу после внедрения, а не «когда-нибудь».
- Если решение отменено, старый ADR не удаляется: ставится `superseded by NNNN`.
- ADR не дублирует код, а объясняет почему.
