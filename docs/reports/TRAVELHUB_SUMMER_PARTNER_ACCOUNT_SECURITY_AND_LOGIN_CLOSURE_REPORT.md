## 2. Исправление plaintext-пароля

### Что сделано

1. **Скрипт seed** (`summer-partner-seed.ts`):
   - Убрана константа `SUMMER_PASSWORD = "Summer2026!"`
   - Реализована генерация случайного пароля через `crypto.randomBytes(16)`
   - Пароль выводится **один раз** в stdout при создании пользователя
   - При повторном запуске (reuse) пароль **не выводится**

2. **Ротация пароля** (`rotate-summer-password.ts`):
   - Сгенерирован новый случайный пароль
   - Старый хеш `Summer2026!` заменён новым
   - `tokenVersion` сброшен в 0 (инвалидация JWT)

3. **Отчёт V2** (`TRAVELHUB_SUMMER_AUTOMATIC_TOUR_CATALOG_V2_IMPLEMENTATION_REPORT.md`):
   - Строка `summer@summertour.az / Summer2026!` заменена на `summer@summertour.az (пароль генерируется случайно при seed)`
