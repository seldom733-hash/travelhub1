### 2. Реализована карусель HeroSection

**Файл:** `frontend/components/marketplace/HeroSection.tsx`

| Параметр | Значение |
|----------|----------|
| Количество слайдов | 3 (hero1, hero2, hero3) |
| Переход | CSS fade (opacity) 700ms |
| Автозапуск | 7 секунд, остановка при наведении/клике |
| Навигация | Стрелки (CaretLeft/CaretRight), индикаторы (pill-style) |
| Цвет активного индикатора | Gold (#D4AF37) |
| Неактивные индикаторы | White, 40% opacity |

**Структура слайдов:**
- Слой 1: Фоновое изображение (обрезано снизу на 64px для обрезки блока Discovery)
- Слой 2: Градиентное затемнение (bottom-overlay)
- Слой 3: Текстовый контент (заголовок, описание, tagline)
- Слой 4: Кнопка "Подробнее" (gold)
- Слой 5: Стрелки навигации (по бокам, над Search/QuickCategories)
- Слой 6: Индикаторы (над Search, по центру)

**Адаптивность:**
- Mobile: высота 540px
- Tablet: высота 580px
- Desktop: высота 620px
- Контент прижат к нижнему краю через `mt-auto pt-0`
