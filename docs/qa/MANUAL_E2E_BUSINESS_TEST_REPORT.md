## 2. Проверка каналов

### Канал A — публичная витрина

Проверено:
- главная страница открывается;
- каталог туров/отелей отображается;
- карточки содержат название, поставщика, цену и даты;
- переход в карточку услуги работает;
- отображается форма параметров тура и календарь цен.

**Результат: BLOCKED на этапе выбора предложения.**  
Календарь не содержит доступных цен для тестовых дат, поэтому модальное окно с формой путешественника и кнопкой «Подать заявку» не открывается.

Причина: live-цены/доступность внешних поставщиков (KOMPAS/SummerTour) не возвращают предложения для выбранных тестовых дат.  
Скриншот: `reports/demo/e2e-product-modal.png`.

Проверено:

## 6. Ограничения

1. Внешние поставщики не возвращают live-предложения для тестовых дат.
2. Без live-предложения нельзя открыть форму путешественника и подать заявку через UI.
3. Платёжные и supplier-payout сценарии требуют тестового платёжного контура/подтверждённых тестовых доступов.
4. Полный аудит по 21 сценарию, ролям и финансовым комбинациям не завершён.

## 7. Следующий шаг

Для продолжения нужен один из вариантов:

- тестовый supplier offer / mock-предложение, доступное в календаре;
- подтверждённый тестовый доступ к KOMPAS/SummerTour с доступными датами;
- разрешение на создание тестовой заявки через внутренний интерфейс менеджера для проверки последующих этапов (с пометкой, что канал подачи отличается).
