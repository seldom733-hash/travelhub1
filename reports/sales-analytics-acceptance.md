| 3 | Сравнительная таблица менеджеров | ✅ | вкладка `Менеджеры` |

| 7 | Завершённые и закрытые сделки | ✅ | `/app/analytics/sales/deals` |

| 11 | Сравнение периодов | ✅ | календарное сравнение месяца/квартала/года/недели |
| 12 | Сохранение фильтров | ✅ | query string между маршрутами |
| 13 | Детализация KPI | ⚠️ | модальное окно с записями; часть финансовых KPI ограничена связанными заявками |
| 14 | Нет двойного учёта | ⚠️ | отменённые заказы исключены; нужна сверка мультисервисных заказов |

| 18 | Финансы соответствуют модели | ⚠️ | `commercialSnapshot.netSupplierCost`, fallback `Booking.amount`; нужна сверка FINANCE |
| 19 | DIRECTOR — полный доступ | ✅ | `sales.kpi.read` в RBAC DIRECTOR |
| 20 | ADMIN — полный доступ | ✅ | ADMIN имеет все права |
| 21 | SALES_MANAGER — только своё | ✅ | backend-фильтр + unit-тест |
| 22 | FINANCE — в рамках прав | ✅ | отдельного управленческого доступа нет |
| 23 | Новые роли не создавались | ✅ | изменения только в существующих правах/запросах |
| 24 | Sales Register не дублируется | ✅ | читаются существующие Request/Order/Booking/finance |
| 25 | Жизненный цикл не нарушен | ✅ | analytics module read-only |
| 26 | Все тесты | ⚠️ | 7 unit-тестов; e2e на реальной БД нет |

## Единственный источник истины

```text
Request → Order → Booking → Payment/Refund
```

Аналитика только читает эти таблицы. Запись в доменные таблицы отсутствует.

## Проверка RBAC в БД

```text
ADMIN         → sales.kpi.read
DIRECTOR      → sales.kpi.read
SALES_MANAGER → sales.kpi.read
SALES_HEAD    → sales.kpi.read
FINANCE       → нет управленческого sales.kpi.read
```
